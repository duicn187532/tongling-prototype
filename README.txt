彤靈談心 Prototype v10

核心流程（9 Steps）
1. 需求說明
2. 知識檢索
3. 補充資料／競品
4. 會議助理
5. AI 分析
6. 人工確認
7. 流程／架構
8. 預覽 PRD
9. 下載 PRD

v10 新增：Knowledge Retrieval
- 使用者提出需求後，系統主動模擬搜尋行內知識庫，不再只依賴使用者自行上傳附件。
- 模擬知識類型：
  * 規章制度
  * 產品／業務知識
  * 系統／技術規格
  * 歷史專案／PRD
- 每筆結果顯示：
  * 相關度
  * 文件版本
  * Owner
  * 更新日期
  * 為什麼與需求相關
  * 命中內容預覽
- 使用者必須自行選擇哪些知識加入案件來源。
- 搜尋相關度不等於權威程度；正式判斷仍需依文件有效性、Owner 與權責確認。
- 已加入的知識會進入：
  * 案件來源清單
  * Requirement Matrix
  * AI Analysis 的 Knowledge Evidence
  * PRD Traceability

Prototype 限制
- 不連接真實企業知識庫。
- 搜尋結果與內容為固定 Mock Data。
- 文件上傳仍不實際解析。
- AI 分析、競品發查、會議助理與圖表仍為情境模擬。
