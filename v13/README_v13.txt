彤靈談心 Prototype v13 — Agentic Workspace

核心改版：
- 廢除 9-step wizard，改成 Define → Investigate → Decide → Publish 四階段。
- Project 內主要工作頁：Mission、Agent Workspace、Requirement Intelligence、Meeting & Change、Impact、Baseline。
- Agent Loop：Understand → Overview → Plan → Execute → Synthesize → Ask User → Re-plan → Exception Handoff。
- Agent 任務分 REQUIRED / CONDITIONAL / SKIP；不需要做的工作會明確顯示原因。
- Human-in-the-loop 改成 Exception-based Review，不再要求逐條人工確認。
- Baseline Publish、重大 Scope、風控／法遵裁決仍保留 Human Gate。
- 企業資產頁加入 Document Hub、System Registry、Interface Catalog、Data Catalog、Crawler、Repo Connector、Task Center 概念。

本版為靜態 Mock Prototype，不連真實模型或後端。
