AGENT GOVERNANCE

AI、自治程度與工具邊界

Prototype 只模擬設定，不會真的送出 API Key。

Autonomy Level

彤靈建議 L3：Agent 自行調查與更新 Draft，高風險／Baseline 仍由人決策。

L0 Manual

AI 只提供資料，不自行規劃。

L1 Assist

AI 建議，每一步由人啟動。

L2 Exception Review

低風險自動處理，例外交人。

L3 Agentic Execution

Agent 自行規劃、工具調用、再規劃；高風險才問人。

Primary AI

Tool / Data Policy

不可由設定關閉：AI 不可自動 Publish Baseline；法遵／風控重大裁決必須 Escalate；Source 權限過濾必須在 Retrieval 前執行。
