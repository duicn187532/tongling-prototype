彤靈談心 Prototype v14 — Guided Agentic Workspace

本版目的：降低 v13 資訊負荷與導覽成本。

核心 UX 改動
1. 主導航縮減為：我的專案、我的待辦、專案工作台、定版與產出、企業知識。
2. Mission / Agent Workspace / Meeting / Impact 不再各自成為必經主頁。
3. 每個專案永遠先顯示「下一步 / Next Best Action」。
4. 一頁只保留一個主要 CTA；其餘為次要或詳細資訊。
5. Human Review 改為 Exception Inbox，不再是固定流程頁。
6. Meeting / Impact / Evidence / Agent Activity 採 Progressive Disclosure：Level 1 行動 → Level 2 解釋 → Level 3 Evidence / Audit Detail。
7. Agent Loop 仍存在於底層，但不直接暴露 Planner / Specialist Agent / Observation 給一般 PM。
8. 補資料採 Guided Human Request：上傳文件、貼上內容、保持 Open、指定再查來源。
9. Agent 判斷 SKIP 任務時只顯示「為何不需要」，避免讓使用者誤以為漏做。
10. Baseline Publish 保留 Human Gate。
